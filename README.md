# Walrus Manager - Android Schedule Management App

## Overview
Walrus Manager is an Android application for managing schedules and events. It provides features for creating, editing, and sharing schedules with remote synchronization capabilities.

## Features
- Create and manage schedules
- Add events with deadlines to schedules
- Share schedules with other users
- Import shared schedules
- Remote schedule synchronization
- Dark mode support
- Countdown timer for events

## Technical Stack
- Language: Java
- Minimum SDK: 26
- Target SDK: 34
- Database: Room (SQLite)
- Remote Database: MySQL
- Architecture: MVVM
